# NestJS API

A simple and scalable RESTful API built with [NestJS](https://nestjs.com/), leveraging TypeScript and Prisma ORM for efficient database interactions.

## 🚀 Features

- Structured project architecture using NestJS modules, controllers, and services
- Database integration with Prisma ORM
- Environment-based configuration management
- Linting with ESLint and code formatting with Prettier
- Ready for Docker deployment (optional)

## 🛠️ Tech Stack

- **Framework:** [NestJS](https://nestjs.com/)
- **Language:** TypeScript
- **ORM:** [Prisma](https://www.prisma.io/)
- **Database:** PostgreSQL (configurable)
- **Linting:** ESLint
- **Formatting:** Prettier
- **Testing:** Jest (optional)
